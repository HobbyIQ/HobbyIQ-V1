# Vintage checklist sources: a permissive source exists, and it is not Beckett

**Survey run 2026-09-04, read-only.** Follows Drew's ruling of the same day:
**no outreach to TCDB** (its ToU forbids automated extraction *and* commercial
reuse — STOP, not negotiable at our end), survey *other* permissive sources for
the vintage cells instead.

> ## Headline
>
> **`www.sportscardchecklist.com` covers every target cell, serves real
> card-by-card checklists, and its robots.txt permits the paths we need.**
> The 2026-09-03 Lane B probe concluded "no permissive vintage
> football/basketball/hockey source identified" and staged zero checklists.
> That conclusion was correct about the sources it probed and **wrong about the
> universe** — this host was not among them. It unblocks an estimated
> **~709,000 pool rows** across the seven target cells.
>
> Two corrections to the prior probe also land here: Beckett's football and
> basketball category pages **do** resolve under a URL form that probe did not
> try (`/news/category/beckett-football/`, HTTP 200) — but the archive still
> has **zero pre-1990 articles**, so the GO is worthless for vintage. And
> Beckett now **403s every request from our egress** (CloudFront), which the
> prior probe did not see.

## 1. Permissions, quoted verbatim before any content fetch

Every document below was fetched with a real browser User-Agent plus a contact

### `www.sportscardchecklist.com` — **GO**

`https://www.sportscardchecklist.com/robots.txt`, HTTP 200, 134 bytes, complete
and verbatim:

```
# Sitemap
Sitemap: https://www.sportscardchecklist.com/site_maps/sitemap.xml

# All Bots
User-agent: *
Disallow: /?*
Disallow: /*.htm$
```

Two disallows, and **neither touches the checklist paths**. The set pages we
want are `/set-<id>/<slug>` — no query string, no `.htm` suffix. The sitemap is
explicitly advertised. `Disallow: /?*` rules out the search endpoint
(`/search/?search_terms=...`), which we therefore **must not use** — the
sitemap is the sanctioned discovery path and is in any case far better (see §3).

**Terms: no terms document is served.** All of these return HTTP 404:

```
/terms  /terms.html  /html/terms.html  /terms-of-use  /terms_of_use.html
/legal  /privacy  /privacy.html  /html/privacy.html  /tos  /about.html
```

`/html/about.html` (HTTP 200, 52,520 bytes) is the only policy-adjacent page.
Its sole ownership statement, verbatim:

```
© 2026 Ultimate Cards and Coins. Trading Card Checklists created and maintained
by GleTech.com, and Sports Card Checklists. All Rights Reserved.
```

A bare copyright reservation. **No scraping clause, no robots clause, no data-
mining clause, no non-commercial restriction** — nothing of the kind TCDB
states explicitly. This is the same posture Beckett has, and the repo already
treats that posture as GO.

> **Caveat, stated plainly.** "All Rights Reserved" is a copyright assertion.
> It does not prohibit access, and card numbers with player names are facts —
> not creative expression — so the *checklist data* is thin-to-uncopyrightable
> in the US (*Feist*). But absence of a terms page is *absence of evidence*, the
> same caveat the 2026-09-03 probe attached to Beckett. The GO rests on the
> permissive robots.txt plus the absence of any prohibition. Attribute the
> source in `card_catalog.source` as we do for every other ingest.

## 3. Coverage: sportscardchecklist.com against every target cell

Discovery is via the advertised sitemap, not the (disallowed) search endpoint.
`site_maps/sitemap.xml` is an index of **30** sitemaps; all 30 fetched, yielding
**141,583 distinct `/set-<id>/<slug>` URLs**.

> **A slug-form gotcha worth recording.** Basketball and hockey sets use
> **split-year** slugs (`1992-93-fleer-...`, `1979-80-o-pee-chee-...`), football
> and baseball use single-year (`1972-topps-football-...`). A year-anchored
> regex that assumes one form reports **0 sets** for basketball 1991-2009 and
> hockey — which is exactly the false negative that makes a live source look
> absent. The fetcher must accept `^(YYYY)(-YY)?-`.
>
> The site's own **search is likewise a false-negative machine**: querying
> `1972 topps football` returns 18 results, **none of them the 1972 Topps
> Football set** — they are 2021 Topps X Trevor Lawrence cards whose *card
> names* contain the string. The set exists at `set-11959`. **Use the sitemap.**

## 6. The exact lane to build next

**Nothing was built this run** — no fetcher, no manifest edit, no staged CSV,
no Cosmos write, no dispatch. This section is the spec for the next PR.

### 6.1 Fetcher child

New source id **`sportscardchecklist`**, alongside the existing checklist
fetchers.

- **Discovery — sitemap only, never `/search/`.** `/?*` is Disallowed. Pull
  `site_maps/sitemap.xml` -> 30 child sitemaps -> filter `loc` to
  `/set-<id>/<slug>`. Cache the 141,583-URL slug list; it is one cheap pass.
- **Cell selection from the slug**, accepting both year forms:
  `^(?<year>\d{4})(-(?<year2>\d{2}))?-(?<rest>.+)-(?<sport>football|basketball|hockey|baseball)-trading-card-checklist$`.
  A missing `year2` is single-year; present means a split season — store
  `cardYear` as the **first** year, matching how the pool spells these.
- **Parse**: card rows are a per-card hidden input,
  `name="ebay_search" value="<set> <number> <player> <subset?>"`. Split on the
  first integer-looking token after the set name. Beware apostrophe escaping in
  slugs (`bowman\s-best` appears literally in sitemap URLs).
- **Emit** per the one checklist format: `cardNumber`, `playerName`,
  `subset`/`variation` from the trailing tag (`LL`, `DP`, `Pro Action`,
  `In Action`, `Record Breaker`, `All-Star`), **`printRun` blank**,
  `parallel` blank unless the *slug itself* names one
  (`-refractors-`, `-gold-`). Never synthesize a parallel — every row traces to
  the scraped page.
- **Politeness**: 1 request at a time, >=2s between, real UA plus contact
  string, honour 429/503 with backoff. Set pages are 0.5-2 MB; 5,799 sets is a
  multi-hour polite crawl. Shard by cell, and **measure rows/s before any fleet
  dispatch** (a prior census went 40x slower undetected).

### 6.3 Order of work, and the gates

1. **Fetcher + parser against the three sampled sets as fixtures**
   (351 / 396 / 80 rows). Exact counts are the regression assertion.
2. **One cell end-to-end first — hockey `o-pee-chee` 1933-1989** (65 sets,
   smallest, and the repo already has a proven 1989 O-Pee-Chee row shape at
   commit `7df1ca16` to diff against). Report the proven diff before widening.
3. **Then football `topps` 1948-1989** (67 sets, the single largest prize at
   289k rows).
4. **Then the basketball cells**, largest first. These are ~5,600 sets and are

5. Write via `patchCatalogRowFields`, **never a raw patch** (#1614). Source

## 7. Caveats

- **No terms page is not a licence.** The GO on `sportscardchecklist.com` rests
  on a permissive robots.txt plus the absence of any prohibition — the same
  standard already applied to Beckett in this repo. If a terms document later
  appears at a path not probed, re-evaluate. Eleven paths were probed.
- **Set counts are sitemap-slug counts**, not verified checklist fetches. Three
  sets were fetched and verified; the other 5,796 are inferred from slug
  patterns. Expect some slugs to be parallels or subsets of a parent set rather
  than distinct base sets — the football `topps` 67 includes items like
  `1981-topps-coca-cola-dallas-cowboys`, and only **34** are plain
  `YYYY-topps-football`. **Rows-unblocked is therefore an upper bound**; the
  proven diff in step 2 is what settles it.
- **Pool-row figures are PR #1689's**, not re-measured here (this run made no
  Cosmos queries at all). The 2026-09-03 probe independently corroborated them
  within rounding.
- **Beckett's 403 may be transient** (CloudFront edge). It does not matter for
  vintage either way — the archive is empty pre-2016.
- All access this run was read-only HTTP GET. **No Cosmos reads or writes, no
  workflow dispatches, no manifest edits, no staged files.**
